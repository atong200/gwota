# Leader art

Drop one image per leader here, named after the leader `id`:

```
game/assets/leaders/<leader-id>.png   (or .webp / .jpg)
```

Example: `game/data/leaders/underlord.json` (`"id": "underlord"`) -> `game/assets/leaders/underlord.png`.

Leaders without art show a placeholder. See [`../cards`](../cards/README.md) for the general rules.
